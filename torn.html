Encontre itens abaixo do mercado.

Em vez de consultar um item de cada vez, pesquise uma seleção de produtos, compare o menor anúncio com um preço de revenda de referência, desconte taxas e veja um ranking de oportunidades hipotéticas. Não executa compras nem vendas.

1. Conectar sua API

Chave não testada.

A chave fica apenas neste campo e vai diretamente à API do Torn via cabeçalho Authorization. Não é gravada em URL, GitHub ou armazenamento local; ao fechar a aba, será necessário colá-la outra vez. Use uma chave de acesso público ou personalizada com permissões torn/items e market/itemmarket.

Para criar uma chave, você precisa ter conta no Torn. Gerenciar chaves →

2. Configurar a busca de oportunidades

Sem informar itens, o programa consulta um conjunto de até 30 produtos do catálogo oficial, distribuídos por categoria e faixa de preço. Isso é uma amostra do mercado, não uma varredura de todos os itens. A circulação informada pela API não mede a velocidade das vendas.

Aguardando pesquisa manual.
Pesquisas somente ao clicar. O mercado do Torn publica cotações com cache global de aproximadamente uma hora; novas consultas podem retornar os mesmos anúncios.

Como interpretar?

Uma oferta barata pode ser uma oportunidade, mas também pode ser um item parado, uma cotação atrasada ou um equipamento com atributos diferentes. Esta versão exclui equipamentos com atributos individuais e considera apenas anúncios comparáveis. Consulte o preço real no jogo antes de comprar e lembre-se da taxa normal de 5% na venda pelo Item Market.
